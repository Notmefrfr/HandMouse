# HandMouse

Control your mouse with hand gestures using an ordinary webcam. Windows 10/11, 64-bit.

## Download
Go to **Releases** (right side of this page), open the newest release and download
**HandMouse-5.2.0-Windows.zip**.

## Install
1. Right-click the ZIP > Extract All.
2. Open the folder and double-click **HandMouse.exe**. No installer and no Python needed.

Windows may say "Windows protected your PC" because the program is new and not digitally signed.
Click **More info**, then **Run anyway**.

More instructions are inside the ZIP (README.txt).
